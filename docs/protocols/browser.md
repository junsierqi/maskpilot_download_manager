# 浏览器与本机协议 v1

扩展默认关闭自动接管和 Cookie 携带。启用后只查询当前发送地址匹配的 Cookie，不读取整份浏览器 Cookie 库。页面资源仅在用户点击时发现。

## 消息格式

原生消息和本机管道均使用 4 字节小端无符号长度，随后为 UTF-8 JSON。单条消息最大 1 MiB，一个本机连接处理一个请求。协议版本固定为 `1`，`requestId` 与 `taskId` 为 32 位小写十六进制字符串。大写及混合大小写编号一律拒绝，避免 Windows 缓存路径大小写别名产生多个任务所有者。持久化任务同样要求小写；异常数据库显式报错，不静默合并编号。

请求示例：

```json
{"version":1,"requestId":"0123456789abcdef0123456789abcdef","command":"prepare","url":"https://example.test/file.zip","filename":"file.zip"}
```

响应示例：

```json
{"version":1,"requestId":"0123456789abcdef0123456789abcdef","ok":true,"taskId":"0123456789abcdef0123456789abcdef"}
```

命令：`ping` 检查连接；`list` 返回最多 1000 条不含来源凭据的任务摘要；`add` 新建任务；`prepare` 持久化暂停任务；`resume`、`pause`、`cancel` 接受 `taskId`。错误响应为 `ok:false` 和简短的 `error`。

`remove` 移除非活动任务的历史记录与本任务缓存，保留最终文件；活动任务须先暂停或取消。该命令同样接受 `taskId`。

新增任务可携带 `filename`、`referrer`、`cookie`、`userAgent` 和 `media`。所有字段有类型和长度检查；只接受 HTTP/HTTPS。文件名必须为单个安全名称，目的目录由桌面设置决定，浏览器不能指定任意路径。媒体任务使用桌面配置的组件。

媒体模式当前处理公开点播来源，不将 Cookie、Authorization 或自定义认证头交给全局媒体组件。携带此类字段时在保存与接管前拒绝；需要登录态的直接文件可使用原生 HTTP 下载。媒体暂停后从头重新获取，避免来源变化后拼接不同版本；原生文件任务保留经身份校验的续传能力。

## 接管顺序

1. 暂停浏览器下载。
2. 发送 `prepare`，桌面端验证并写入数据库后才确认。
3. 取消浏览器下载，再发送 `resume`。
4. 准备失败则恢复浏览器；取消浏览器失败则取消原生暂停任务并恢复浏览器；恢复原生任务失败时保留已持久化的暂停任务并明确提示。

相同请求编号重试不会创建多个任务；编号不能用于另一资源。对取消、暂停等控制的响应表示命令已接受，最终状态由 `list` 查询。恢复命令在崩溃前尚未持久化时，已准备的暂停任务仍可恢复。

## 本机边界

原生 host 校验已注册扩展来源；桌面使用当前用户可访问的命名管道和每次启动生成的私有 token。token 不进入浏览器、任务列表或诊断内容。没有公开本地 HTTP 控制端口。

安装脚本只注册本项目的当前用户 host 项；卸载只移除仍指向本安装的注册项。商店分发和签名是单独的发布环节。

## 当前代理与环境边界

协议 v1 未定义浏览器客户端选路或代理凭据字段，任务使用桌面提供的默认路由；额外 JSON 字段不能作为选路已经生效的证据。直接文件及 BT 的代理账号密码由任务代理页或 CLI 单独提供，源站 `Authorization`／`Cookie` 与代理认证分离。自定义请求头不能设置 `Proxy-Authorization` 或 `Proxy-Connection`。

当前扩展来源检查证明已注册扩展身份，不证明它属于哪个指纹浏览器环境；当前列表与控制仍是独立下载管理器的范围。浏览器环境隔离及安全凭据管理是下一独立切片，不能用这个来源检查代替。后续集成须由浏览器的 Profile Core／Proxy Core／Browser Storage／Browser Bridge 提供可信归属、路由和按地址授权的凭据，再由下载服务校验任务所有权；不读取浏览器私有数据库，不信任网页自行声明的环境编号。
