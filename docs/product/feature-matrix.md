# 功能与验收映射

编号沿用开发蓝图。实现不等于所有平台／环境均已验收；外部环境和持续测试的剩余项目记录在发布验收中。

## 当前覆盖程度

当前候选版覆盖核心下载流程，**没有完成最初的完整功能目标**。蓝图中的目标项不能仅因有对应入口就标为全部完成；以下差距仍需工程实现和独立验收，并非用户已经同意取消的需求。

| 能力 | 当前实现 | 缺失部分 |
|---|---|---|
| 分段 | 开发代码支持开始时划分及空闲连接拆分剩余大段；最多 8 个活动连接、256 个持久化段，支持单流降级 | 公网服务器吞吐兼容与新版本长期验收 |
| 队列与计划 | 命名队列、独立并发／带宽、手动暂停与策略等待、公平调度、优先级、一次性开始／停止、每周时区窗口、HTTP/FTP 正文 UTC 日／保守滚动额度 | BT／媒体用量预算、逐字节滑动计量、运营商线路流量限制 |
| 批量与站点 | 文本／模板／页面资源发现、逐项确认与重试；公开同来源站点递归、深度／路径前缀／类型筛选、预览、离线重写、不可变修订、手动更新与有界周期完整同步 | 其他来源范围、动态应用及登录页面还原、增量去重与旧版本自动清理 |
| 协议与认证 | HTTP/HTTPS、FTP/FTPS、BT／磁力、自定义 HTTP 认证头、Cookie、FTP 内存凭据、可选系统代理凭据保存及环境隔离；BT HTTP CONNECT／SOCKS5 TCP 代理，媒体认证 HTTP／SOCKS5 代理 | 交互式源站认证、BT HTTPS／UDP 代理 |
| 浏览器与媒体 | Chrome／Edge 开发者扩展、Firefox 150+ 临时扩展、可选页面面板与资源列表、公开点播组件、实际格式探测／精确选择及容器校验 | 浏览器商店签名发行、其他浏览器适配、分区／隐私登录材料、持续站点兼容验收 |
| 桌面管理 | 分类、搜索、历史、导入导出、托盘、双语 | 更完整的工具栏／列／主题自定义、完成后外部扫描程序 |
| 交付 | 本地便携包、按用户安装；开发分支增加可信哈希校验的离线升级、恢复、安装文件回滚与受控清理 | 在线更新发现、签名和商店发行、干净系统兼容验收；新版长测完成前不能标为发布通过 |

直播、受保护媒体绕过、其他桌面平台及额外协议不能算作已实现。覆盖范围仍须按具体版本逐项验证；这里列出的差距也不构成对任意外部产品的完整一致性认证。

## 上下文增量

安全凭据存储与上下文应用核心、v2 本机 broker 是分开交付的基础模块：任务归属／去重、路由快照、源站授权和撤销由同一协调线程管理，普通接口只输出当前上下文摘要。已有扩展仍是 v1 独立下载区客户端。系统凭据保存／忘记、环境管理、筛选、新建、重新绑定、撤销／恢复及导入重试已连接真实 Qt 控件并有自动回归。凭据撤销完成后同步清空持久化引用；失败可重试。实际指纹浏览器端签发、多 DPI 和干净系统验收仍不能据此标记完成。
