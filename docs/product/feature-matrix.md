# 功能与验收映射

编号沿用开发蓝图。实现不等于所有平台／环境均已验收；外部环境和持续测试的剩余项目记录在发布验收中。

## 当前覆盖程度

当前候选版覆盖核心下载流程，**没有完成最初的完整功能目标**。蓝图中的目标项不能仅因有对应入口就标为全部完成；以下差距仍需工程实现和独立验收，并非用户已经同意取消的需求。

| 能力 | 当前实现 | 缺失部分 |
|---|---|---|
| 分段 | 开始时固定划分，最多 8 段，支持单流降级 | 下载过程中拆分剩余大段、动态再分配连接 |
| 队列与计划 | 单个全局队列、优先级、一次性开始／停止 | 多命名队列、周期计划、周期同步、按流量配额停止 |
| 批量与站点 | 文本链接、数字模板、当前页面资源发现 | 递归抓取、深度／域名／文件过滤、离线页面链接重写、项目定期更新 |
| 协议与认证 | HTTP/HTTPS、FTP/FTPS、BT／磁力、自定义 HTTP 认证头、Cookie、FTP 内存凭据 | BT 代理、交互式认证、完整代理认证与凭据管理 |
| 浏览器与媒体 | Chrome/Edge 开发者扩展、资源列表、公开点播组件、预设画质上限及音频／视频模式 | Firefox／其他浏览器适配、页面浮动下载面板、按地址探测实际格式／清晰度列表、持续站点兼容验收 |
| 桌面管理 | 分类、搜索、历史、导入导出、托盘、双语 | 更完整的工具栏／列／主题自定义、完成后外部扫描程序 |
| 交付 | 本地便携包和按用户安装 | 在线更新通道、签名和商店发行、干净系统兼容验收 |

直播、受保护媒体绕过、其他桌面平台及额外协议不能算作已实现。覆盖范围仍须按具体版本逐项验证；这里列出的差距也不构成对任意外部产品的完整一致性认证。

## 已有实现与证据边界

| 编号 | 实现入口 | 验证与边界 |
|---|---|---|
| F-01 | 原生 transport、请求高级选项 | HTTP 故障矩阵、重定向／凭据／代理；认证能力见支持矩阵 |
| F-02（部分） | multi 固定分段、单流降级 | 64 位分段测试、实际 Range 与忽略 Range 路径；尚无动态拆段 |
| F-03 | offset/identity sidecar、SQLite | 实际强制退出恢复、远端身份改变、无 ETag 重下 |
| F-04 | DownloadService、设置、右键优先级 | 控制／时间边界／混合预算测试；压力脚本检查 100 队列、8 活跃、8 段 |
| F-05 | 历史列表、分类设置、导入导出 | 导入先整体验证再新增暂停任务；不导出请求头与登录凭据 |
| F-06（部分） | 一次性开始／停止、完成动作 | 无周期／多队列计划；计划边界单测；真实休眠唤醒和关机行为未自动触发 |
| F-07 | MV3、native host、用户 IPC | 真浏览器接管与回退；最终生产浏览器策略与商店安装待外部验收 |
| F-08 | Qt 窗口、详情、设置、托盘 | 实际控件新增流程和原生截图；多 DPI／多屏人工验收另列 |
| F-09 | 批量对话框、扩展资源发现 | URL 模板、去重、预览与数量上限；不包含递归抓站 |
| F-10 | 统一媒体 adapter | 实际 MP4、HLS、DASH、音轨／视频合并和 M4A；仅公开点播，恢复重下 |
| F-11（部分） | 可选解析组件、组件管理 | 组件缺失／错误可诊断；尚无持续维护的外部站点支持名单与兼容验收 |
| F-12 | 更新 URL／请求、身份校验 | 同标识不同 URL 不混合缓存；凭据刷新仅进程内生效 |
| F-13 | SHA、同卷发布、错误状态 | 错误 Range／校验失败不发布，同名不覆盖；完整磁盘异常环境验收另列 |
| F-14 | 双语、安装／卸载、动态部署、迁移 | v1 数据迁移与备份；打包 smoke 移除开发 PATH；干净系统仍需独立环境 |
| F-15（部分） | FTP/FTPS 独立适配器与桌面请求选项 | 本地 FTP/TLS 故障夹具；不含远程目录浏览／递归抓站，详见支持矩阵 |
| F-17（部分） | 独立 BT 引擎、统一任务、文件选择与做种 | 本地 v1/v2/混合种子与磁力、纯 Tracker、恢复及限速做种验证；BT 代理、多源镜像、远程控制和插件尚未实现 |
| F-16、F-18 | 后续范围 | Firefox 及其他桌面平台／无界面服务未交付，详见支持矩阵 |
