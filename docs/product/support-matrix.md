# 支持范围

| 能力 | 当前行为与边界 |
|---|---|
| 平台 | 目标 Windows 10 1809+／Windows 11 x64，Qt Widgets；当前实测主机为 10.0.26300.0，Windows 10 与干净系统尚未验证；其他系统未提供发布包 |
| 文件传输 | HTTP/HTTPS、开始时固定划分最多 8 段、每任务单流降级、未知长度和空文件；TLS 验证开启。未实现下载中的动态拆段再分配 |
| 恢复 | 强 ETag、长度、实际 URL 和分段布局共同验证；无可靠身份则重新下载；崩溃后任务暂停待恢复 |
| 登录与代理 | 直接文件支持 Cookie、自定义 Authorization／请求头、HTTP 代理；凭据不持久化。没有自动交互式登录、代理密码管理或任意认证协议协商 |
| 调度 | 1–8 活跃任务、优先级、单任务／全局限速、一次性本地时间计划。减小并发先让现有任务排空；媒体预算在批次排空前保守保留 |
| 完成动作 | 通知、退出、关机；后两者有 60 秒倒计时，出现新任务即撤销。只接受明确的动作值 |
| 浏览器 | Chrome/Edge MV3、原生消息、右键发送、资源发现、可选自动接管；开发者模式加载。自动接管失败尽量恢复浏览器任务并明确报告恢复失败 |
| 批量 | 文本／静态页面资源链接、URL 数字模板、去重和数量上限；不是完整递归网站抓取 |
| 媒体 | 本地自有公开 MP4、HLS、DASH 点播样例已做实际解析／合并验证；MKV 视频与 M4A 音频。恢复重新下载，不宣称可靠媒体续传 |
| 网页媒体 | 用可选解析组件处理公开地址；没有“任意网站均支持”保证，也没有持续维护的外部站点验收名单。缺组件、站点拒绝和解析失效均返回错误 |
| 媒体安全 | 不支持携带 Cookie／Authorization／自定义头的媒体任务、直播、DRM 或付费保护绕过。可选 Node 运行时仅在已安装时使用 |
| 文件发布 | 同卷临时文件、可选 SHA-256、禁止覆盖同名文件；删除记录保留最终文件 |
| 数据 | SQLite 版本化迁移，升级前备份；拒绝未知未来版本。导入先验证，新增任务默认暂停 |
| 更新 | 手动安装新包保留用户数据；没有已发布的在线更新服务、签名证书或商店条目 |

后续版本另行定义：FTP/FTPS、Firefox、BT／磁力、多源镜像、远程控制、插件和其他桌面平台。不要把未实现的协议归入当前功能。

多命名队列、周期／同步计划、递归站点抓取、流量配额、完成后外部扫描、按地址探测实际格式／清晰度列表及在线更新也尚未实现。媒体对话框已有预设画质上限，不能等同于实际格式列表。完整功能目标仍有差距，见 [功能与缺口](feature-matrix.md)；这里的版本范围不是完整目标已经交付的声明。

系统最低版本依据 [Qt 6.11 官方 Windows 支持说明](https://doc.qt.io/qt-6.11/windows.html)；依赖支持范围不等同于本产品已完成对应系统验收。

原生消息仅用于当前用户本地通道，使用每次启动的令牌与来源检查；不提供远程监听服务。相同 Windows 用户权限下的恶意软件不在本地令牌的隔离保证内。
