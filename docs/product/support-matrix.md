# 支持范围

| 能力 | 当前行为与边界 |
|---|---|
| 平台 | 目标 Windows 10 1809+／Windows 11 x64，Qt Widgets；当前实测主机为 10.0.26300.0，Windows 10 与干净系统尚未验证；其他系统未提供发布包 |
| 文件传输 | HTTP/HTTPS、开始时固定划分最多 8 段、每任务单流降级、未知长度和空文件；TLS 验证开启。未实现下载中的动态拆段再分配 |
| FTP/FTPS | 独立单流适配器；匿名／账号登录、主动／被动模式、显式／隐式 TLS、私有 CA。校验证书和主机名，TLS 失败不降级；账号密码仅内存保存 |
| FTP 恢复 | 提供预期 SHA-256 且 URL、大小、修改时间、TLS 选项匹配才尝试 REST，发布前验证摘要；无可靠条件或 REST 被拒绝则重下。SIZE/MDTM 不被当作强内容标识 |
| BT／磁力 | 独立共享会话；本地 v1、v2、混合种子与磁力、Tracker 获取元数据、选择文件、分片校验、暂停恢复、可选做种、上传统计及任务／全局上传限速。种子元数据 ≤16 MiB，文件 ≤20,000；初始 peer／Tracker／web seed 列表各 ≤256。本地回环实测不代表公网 DHT／所有种源可达 |
| BT 文件与隐私 | 使用专属目录，禁止覆盖已有目标；删除记录或取消做种保留已发布内容。种子元数据随任务库与导出清单保存，可能含私有 Tracker/passkey；原始文件捕获拒绝网络、设备、重解析路径 |
| 恢复 | 强 ETag、长度、实际 URL 和分段布局共同验证；无可靠身份则重新下载；崩溃后任务暂停待恢复 |
| 登录与代理 | 直接文件支持 Cookie、自定义 Authorization／请求头、HTTP／HTTPS／SOCKS5 代理及独立代理账号密码；默认凭据仅内存保存。空地址明确直连，指定路由覆盖环境代理绕过，SOCKS5 目标 DNS 由代理解析；没有自动交互式源站登录 |
| BT 代理 | HTTP CONNECT／SOCKS5 TCP 传输，按路由与凭据隔离活动会话；关闭 DHT／本地发现／uTP／自动端口映射，不支持 UDP Tracker 或 HTTPS 代理。源站失败保留原生重试与备用节点能力，不回退直连 |
| 代理恢复 | 任务库／清单保留无秘密端点及凭据需求标记；恢复前需重新输入凭据。标记不强制服务器发起认证挑战。代理主机名使用原生／系统解析；五秒额外连通性检查只适用于数字 IP。主动 FTP＋代理明确拒绝 |
| 调度 | 1–8 活跃任务、优先级、单任务／全局限速、一次性本地时间计划。减小并发先让现有任务排空；媒体预算在批次排空前保守保留 |
| 完成动作 | 通知、退出、关机；后两者有 60 秒倒计时，出现新任务即撤销。只接受明确的动作值 |
| 浏览器 | Chrome/Edge MV3、原生消息、右键发送、资源发现、可选自动接管；开发者模式加载。自动接管失败尽量恢复浏览器任务并明确报告恢复失败 |
| 批量 | 文本／静态页面资源链接、URL 数字模板、去重和数量上限；不是完整递归网站抓取 |
| 媒体 | 本地自有公开 MP4、HLS、DASH 点播样例已做实际解析／合并验证；MKV 视频与 M4A 音频。恢复重新下载，不宣称可靠媒体续传 |
| 网页媒体 | 用可选解析组件处理公开地址；没有“任意网站均支持”保证，也没有持续维护的外部站点验收名单。缺组件、站点拒绝和解析失效均返回错误 |
| 媒体安全 | 不支持携带 Cookie／Authorization／自定义头的媒体任务、直播、DRM 或付费保护绕过。可选 Node 运行时仅在已安装时使用 |
| 文件发布 | 同卷临时文件、可选 SHA-256、禁止覆盖同名文件；删除记录保留最终文件 |
| 数据 | SQLite 版本化迁移，升级前备份；拒绝未知未来版本。导入先验证，新增任务默认暂停 |
| 界面 | Qt Widgets 中英文界面、协议／分类筛选、文件名与来源、下载进度及上传速度；较窄窗口自动隐藏大小、分类、剩余时间等次要列，任务详情保留完整信息 |
| 更新 | 手动安装新包保留用户数据；没有已发布的在线更新服务、签名证书或商店条目 |

后续版本另行定义：Firefox、多源镜像、远程控制、插件和其他桌面平台。BT 基础传输已接入，不等同于完整专业种子客户端的全部高级设置；公网、防火墙及私有 Tracker 兼容性仍需独立验收。

多命名队列、周期／同步计划、递归站点抓取、流量配额、完成后外部扫描、按地址探测实际格式／清晰度列表及在线更新也尚未实现。媒体对话框已有预设画质上限，不能等同于实际格式列表。完整功能目标仍有差距，见 [功能与缺口](feature-matrix.md)；这里的版本范围不是完整目标已经交付的声明。

系统最低版本依据 [Qt 6.11 官方 Windows 支持说明](https://doc.qt.io/qt-6.11/windows.html)；依赖支持范围不等同于本产品已完成对应系统验收。

原生消息仅用于当前用户本地通道，使用每次启动的令牌与来源检查；不提供远程监听服务。相同 Windows 用户权限下的恶意软件不在本地令牌的隔离保证内。

## 上下文与凭据开发边界

开发代码的应用层提供不可变任务归属、上下文内请求去重、固定路由快照、短期精确 URL 授权和撤销退出屏障。桌面通过 v2 本机 broker 接入；管理权限、v1 独立下载区和普通上下文会话分开。系统凭据保存有真实原生存储与故障恢复测试，默认不保存。上下文和凭据管理控件仍需独立验收；当前扩展继续使用 v1 独立下载区，不能把扩展来源检查视为指纹浏览器配置识别。实际浏览器侧签发遵守其工程边界另行接入。
